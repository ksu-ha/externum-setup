
# Externum Setup

Графический установщик и мастер подготовки комплекса Externum для Astra Linux.

## Возможности

- Графический мастер на PyQt5.
- Семь предварительных проверок.
- Круговой индикатор готовности.
- Проверка сетевой конфигурации.
- Выбор и проверка ISO.
- Монтирование ISO в режиме read-only.
- Запуск внешнего установочного сценария.
- Отслеживание процесса и кода завершения.
- Повтор операции после ошибки.
- Маскирование секретов.
- Журналирование.
- Экспорт диагностического TAR.GZ.
- Демонстрационный режим Windows.

## Требования

Для разработки:

- Python 3.9+
- PyQt5
- PyInstaller

Для реального выполнения:

- Astra Linux
- Права администратора для системных операций
- Утилиты bash, mount, umount, ip, tar
- Установочный сценарий Externum

## Запуск в Windows

Создать виртуальное окружение:

```powershell
python -m venv .venv
```

Активировать:

```powershell
.venv\Scripts\Activate.ps1
```

Установить зависимости:

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Запустить:

```powershell
python main.py
```

В Windows доступен демонстрационный режим.

Реальное изменение системных параметров и монтирование ISO не выполняются.

## Запуск в Astra Linux

Установить Python и PyQt5 в среде разработки.

Запустить приложение:

```bash
python3 main.py
```

Для выполнения операций, требующих прав администратора, приложение должно быть запущено с соответствующими полномочиями.

Не запускайте установщик на рабочей машине без резервной копии и согласованного плана восстановления.

## Установочный сценарий

По умолчанию приложение ищет:

```text
./install.sh
```

Можно указать другой путь:

```bash
export EXTERNUM_INSTALL_SCRIPT=/opt/externum/install.sh
python3 main.py
```

Сценарий должен быть неинтерактивным, возвращать корректный код завершения и не запрашивать ввод через терминал.

Код завершения 0 означает успешное завершение сценария. Любой другой код означает ошибку.

## ISO

Приложение проверяет:

- существование файла;
- расширение ISO;
- минимальный размер;
- сигнатуру ISO 9660.

Монтирование выполняется только в Linux и только для чтения.

## Журнал

Windows:

```text
%LOCALAPPDATA%/externum/logs/
```

Linux:

```text
~/.local/state/externum/logs/
```

## Диагностический отчёт

В отчёт TAR.GZ входят:

- report.json;
- README.txt;
- журнал приложения.

Секреты маскируются.

Перед передачей отчёта третьим лицам рекомендуется проверить его содержимое.

## Тестирование

Установить pytest:

```bash
pip install pytest
```

Запустить:

```bash
python -m pytest tests -v
```

## Сборка Windows Preview

```powershell
pyinstaller --noconfirm --clean --windowed --name ExternumSetup main.py
```

Результат:

```text
dist/ExternumSetup/ExternumSetup.exe
```

## Сборка Astra Linux

Собирать приложение следует в целевой Astra Linux или в совместимой среде с той же архитектурой и ABI.

```bash
python3 -m pip install pyinstaller
pyinstaller --noconfirm --clean --windowed --name ExternumSetup main.py
```

Результат:

```text
dist/ExternumSetup/
```

Для получения одного исполняемого файла:

```bash
pyinstaller --noconfirm --clean --onefile --windowed --name ExternumSetup main.py
```

Результат:

```text
dist/ExternumSetup
```

PyInstaller не является кросс-компилятором. Windows EXE не заменяет сборку под Astra Linux.

## Безопасность

- Не записывайте пароли в журнал.
- Не передавайте секреты в аргументах командной строки.
- Не храните секреты в состоянии установщика.
- Не запускайте неизвестные ISO и сценарии.
- Проверяйте контрольные суммы образов.
- Проверяйте содержимое диагностического отчёта перед отправкой.
