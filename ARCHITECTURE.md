# Архитектура Externum Setup

## Общая схема
[ Графический интерфейс (PyQt5) ]
              ↓ (CLI-аргументы: --system-type, --project-server, --user, --apt-iso)
[ Оригинальный install.sh (Режим --mode cli) ]
              ↓ (Генерирует /tmp/inventory.yml)
[ under-install.sh ]
              ↓ (Запускает Ansible)
[ Ansible Playbooks (install-single-node.yml / install-multi-node.yml) ]
              ↓
[ Docker-контейнеры Externum ]

## Разделение ответственности
* **GUI (PyQt5):** Сбор параметров, валидация (IP, SSH, NTP, ISO), визуализация прогресса, сбор диагностики, формирование отчета TAR.GZ.
* **install.sh:** Оригинальный скрипт от РЕГЛАБ. Мы не переписываем его. Он отвечает за создание `inventory.yml` и запуск Ansible.
* **Безопасность:** Пароль SSH передается в `install.sh` через переменную окружения `EXTERNUM_SSH_PASSWORD`, а не через аргументы командной строки. В логах и отчетах пароли маскируются с помощью `core/security.py` (regex-паттерны `password=`, `token=`, `Bearer`).

## Демонстрационный режим
Для безопасной демонстрации без реальной установки Docker-контейнеров используется stub-скрипт `usb-disk/install.sh`. Он принимает те же аргументы, что и оригинальный скрипт, и возвращает коды `0` (успех) или `5` (ошибка). Это позволяет показать интеграцию без 40-минутной установки.
